Answer to your FR-0010 question:

It is a data hand-off, not just sequencing. AH-IPP results are passed to CCM and the AI Model inside the request payload, in the field AHIPPLIST.

How it works:
- When calling CCM and the AI Model, CMiC builds the request payload with constructAiObject.
- AHIPPLIST is a field of AIOBJECT. Inside constructAiObject, there is logic that sets AHIPPLIST:
  1. Get the result file name from IPPLOG (SEQ value to be confirmed from code).
  2. Download the document from Azure Storage Account.
  3. Parse the content from string to JSON.
  4. Set the parsed JSON into AHIPPLIST.
